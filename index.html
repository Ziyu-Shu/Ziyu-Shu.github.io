nba-shot-make-model

Estimates the probability that an NBA shot goes in, using 425K shots with player-tracking features such as defender closing speed and contest pressure plus shooter and defender profiles. Built in R with LightGBM, leave-one-season-out validation and TreeSHAP. Reaches 0.622 log-loss on a fully held-out season vs. a 0.690 baseline, with well calibrated probabilities.

Python PyTorch Geometric Graph Neural Networks

thgnn-conflict-prediction

Predicts militarized interstate conflict by modeling the world as yearly heterogeneous graphs (1816 to 2012) with alliance, conflict and contiguity edges, plus a fixed-effects panel regression on alliance centrality. Built with PyTorch Geometric (HeteroConv + GAT) on Correlates of War and Polity5 data. Reaches AUC 0.794 ± 0.04 over 5 seeds vs. 0.772 for a logistic regression baseline.

Python LLM-as-Judge AI Safety

jailbreak-eval-experiments

Diagnoses and reduces false positives in an LLM-judge jailbreak safety evaluator built within the MLCommons project. Python experiment harness with versioned scorer rubrics, single-variable ablations, a stratified train/test split and FPR/TPR scoring with McNemar tests. Traced the 38% false-positive rate to scorer severity inflation: 95% of false positives carried no ground-truth top-severity label.

Python SQLite Data Pipelines

multi-ats-job-pipeline

Ingests job postings from five Applicant Tracking Systems (Workday, Greenhouse, Lever, Ashby, Paylocity) into an incremental store that tracks new, edited and closed postings. Built in Python with SQLite, pydantic and a rules-first extractor that only falls back to Claude models when needed. Holds 4,223 open postings and extracts descriptions at about 3 ms and $0 per page with 86.7% completeness and 0% boilerplate.
